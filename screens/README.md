# Снимки экрана

| Папка | Что внутри | Статус |
|---|---|---|
| `site/` | страницы сайта на 1280, 768 и 375 px, мобильное меню, ошибки формы | ✅ |
| `lighthouse/` | PageSpeed Insights / Lighthouse, главная, мобильный режим | ✅ |
| `sheets/` | заявка в листе `leads` с метками | ✅ |
| `ga4/` | DebugView по каждому событию (`<имя_события>.png`), пользовательские параметры, правило `lang_to_language`, ключевые события | частично |
| `utm/` | адресная строка после перехода по каждой ссылке реестра (`u-01.png`…), короткая ссылка, Traffic acquisition | после публикаций |
| `instagram/` | ManyChat Live, ответ в комментариях, Direct с кнопкой, ветка КИТАЙСКИЙ | после настройки |
| `reports/`, `explore/` | отчёты и исследования раздела 8 | через 24–48 ч после проверок |
| `datalens/` | три вкладки дашборда | после настройки |
